# 独立系特派員の加入イベント

`CA_CorrespondentJoin` は、プレイヤー拠点マップがある任意の開始シナリオを対象にするアルファ版のストーリーテラーイベント。発生日7日目以降、再発間隔45日、基礎確率0.15は調整用の仮値であり、発生を保証する値ではない。

申し出は `CA_CorrespondentOffer` の選択付きレターに保存する。受諾時だけ開発用カエラヴィPawnをプレイヤー勢力として生成し、拒否時は生成しない。保留中は後から開き直せる。対象拠点が失われた場合は受諾を表示せず、拒否できる。年齢・装備・背景・職務、発生頻度は未決定であり、現時点の成人・無装備は検証用の仮値。

ロード・保存再読込・受諾・拒否・拠点喪失時の挙動はゲーム内で確認する。DLLの型と保存経路の確認だけを、実機動作の確認として扱わない。
