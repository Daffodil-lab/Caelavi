# 義翼のアルファ版実装記録

2026-09-24。Core 1.6の`AddedBodyPartBase`、`BodyPartProstheticMakeableBase`、`SurgeryInstallBodyPartProstheticBase`を継承する。`CA_Wing`が左右共通の部位Defなので、手術の対象部位を`CA_Wing`に指定して左右のBodyPartRecordを選べる構成とした。手術は`CA_Caelavi`専用。通常の傷の手当てや既存の再生治療を置き換えない。

## 調整用の仮値

| 値 | アルファ版 | 理由 |
|---|---:|---|
| 部位効率 | 1.0 | 義翼の飛行性能差が未採用なので、まず欠損復旧経路を検証するため |
| 材料 | スチール60、コンポーネント5 | Core義手の40・4より大きい翼として仮置き |
| 質量 | 4 kg | 装備・交易確認用の仮値 |
| 製作工数 | 17000 | Core義手基底の15000より少し多く仮置き |

製造台・研究・医療品・医術条件はCoreの義肢基底に従う。義翼の正式な性能・材料・研究費は未決定。現在の飛行判定は欠損していない翼を数えるため、義翼設置後の飛行倍率は専用の性能差としてまだ調整していない。

## 新規仮素材

`Textures/Caelavi/Items/ProstheticWing.png`は透明背景の128×128ピクセルの仮アイコン。既存の画像は読み込まず、`tools/generate_prosthetic_wing_icon.py`の図形・色指定だけで生成した。再生成はPillowを利用できるPython 3で次を実行する。

```sh
python3 tools/generate_prosthetic_wing_icon.py
```

アイコンは正式な義翼デザインとして採用していない。

## 確認の境界

XML構文、参照、透過PNG、C#ビルドの静的確認と、ゲーム内の手術確認を分けて記録する。ゲームでは左右を別々に欠損・手術し、健康タブ、描画、飛行段階、保存読込、義翼を外した場合の回収を確認する。静的検査だけでは手術対象に出ることや欠損が実際に回復することは証明しない。
