# バニラの鳥の受精卵とカエラヴィへの応用

調査日：2026-09-19。独立リポジトリへの移管：2026-09-23。

ユーザー指定「産卵関連はバニラの鳥の受精卵のシステムを調べる」に対応する調査記録。ゲーム定義やMODコードは変更していない。第2〜4節の数値はバニラの参考値であり、カエラヴィの仕様として採用した値ではない。カエラヴィの採用設定は第5節に記す。

本書は旧RIM作業領域で得た調査結果と採用済み設定を、独立した`Daffodil-lab/Caelavi`のアルファ版開発資料として移したもの。旧試作の実装やゲームDLLは含めない。**既知の素材（PNG・KRA・ORA・Blender等）は当面使用しない。** 以下のゲーム処理は記載した版を調査した知見であり、本リポジトリの実装済み機能ではない。未決定の詳細を全て確定することは、アルファ版着手の前提にしない。進め方は[アルファ版開発ガイド](alpha-development-guide.md)を参照する。

## 1. 確認方法と結論

インストール済みRimWorldのCore XMLと、`Assembly-CSharp.dll`の該当メソッドのILを読み取り確認した。実機の産卵・孵化試験は未実施。

- `Version.txt`：**1.6.4871 rev595**。
- DLL SHA-256：`6d06b881d59cb54d05b674e8631fa2e8b1629dc8b8dd294a5bcc928f1e5d2148`。
- **バニラは、親が抱卵し続けなくても、受精卵が時間経過で孵化する仕組み。** 孵卵器や専用の保温作業は必須条件にない。
- **卵には母親・父親・所属勢力の参照を保存する。** 親子関係の登録処理もある。ただし、遺伝子の継承と、人型種族の出生処理全体が揃うわけではない。
- 人型の自然生殖と動物の交尾・産卵は別の経路。`EggLayer`を人型へ追加するだけでは、今回の出生仕様は完成しない。

## 2. 受精から孵化まで

| 段階 | バニラで確認した処理 | 主な処理名 |
|---|---|---|
| 受精 | 動物の交尾後、雌に産卵Compがあれば受精枠を設定し、父親の参照を保存する。不妊の場合は進まない | `PawnUtility.Mated` → `CompEggLayer.Fertilize` |
| 卵の形成 | 産卵進行度を蓄積。産卵間隔、生活段階、雌限定設定、不妊、空腹に応じた資源成長速度等を参照する | `CompEggLayer.Active / CompTick` |
| 産卵場所の選択 | プレイヤー所属なら利用可能な卵箱を探す。なければ周辺の同種卵や地面へ産む経路がある | `JobGiver_LayEgg` |
| 産卵 | 受精枠が残っていれば受精卵、なければ無精卵。卵数分の受精枠を消費し、形成進行度をリセット。孵化Compへ両親と勢力を渡す | `CompEggLayer.ProduceEgg`、`JobDriver_LayEgg` |
| 卵の成長 | 設定日数に応じて孵化進行度を増やす。抱卵者、燃料、電力、卵箱の有無は孵化進行の条件にない | `CompHatcher.CompTick` |
| 温度被害 | 安全範囲外の温度差と滞在時間に応じて被害を蓄積。100％で孵化不能になる | `CompTemperatureRuinable.CompTick` |
| 孵化 | 卵に指定されたPawnKindから子を生成し、出現処理と親子関係の登録を行う。スタック個数分を生成して卵を消す | `CompHatcher.Hatch`、`PawnUtility.TrySpawnHatchedOrBornPawn` |

産卵進行は2500 tickごとに更新され、空腹による補正もあるため、XMLの産卵間隔があらゆる状況での正確な産卵時刻を保証するわけではない。生活段階の判定には、名称に反して産卵にも使われる`milkable`フラグを参照する。

### ニワトリの参考値

| 設定 | 値 |
|---|---|
| 基本の産卵間隔 | 1日 |
| 一度の産卵数 | 1個 |
| 一度の受精で設定される受精枠 | 1個分 |
| 孵化に要する時間 | 3.5日 |
| 受精卵の安全温度 | 0～50℃ |
| 未受精時の形成上限 | 100％。無精卵を産める |

`Fertilize`は受精枠を加算するのではなく、設定された最大値へ戻す処理。ニワトリでは1回の受精後に受精卵1個を産む。

### 全ての鳥が同じ周期ではない

| 鳥 | 基本の産卵間隔 | 孵化日数 | 未受精時の形成上限 |
|---|---:|---:|---:|
| ニワトリ | 1日 | 3.5日 | 100％ |
| アヒル | 1日 | 3.5日 | 100％ |
| ガチョウ | 2日 | 6.5日 | 100％ |
| シチメンチョウ | 1.333日 | 5日 | 50％ |
| エミュー | 3.33日 | 6日 | 50％ |
| ヒクイドリ | 3.33日 | 7日 | 50％ |
| ダチョウ | 3.33日 | 8日 | 50％ |

50％設定の鳥は、受精していない状態ではそこで進行が止まり、産卵可能な100％へ到達しない。**無精卵を継続して産ませない方式も、バニラに既にある。** 上記7種は一度の卵数・受精枠ともに1。

## 3. 保管・温度・腐敗

- **卵箱は必須の孵卵器ではない。** 屋外での劣化を防ぐが、温度被害は防がない。親が箱に座り続ける条件もない。
- 温度被害の速度は、安全温度から外れた温度差に比例する。共通受精卵設定は`progressPerDegreePerTick = 0.00003`。
- 安全温度へ戻すと新たな温度被害は止まるが、確認した更新処理に蓄積被害の自然回復はない。温度被害100％未満なら孵化進行自体は継続する。
- 生きた受精卵では通常の腐敗を無効化する設定がある。温度被害で孵化不能になると、この腐敗抑止の条件から外れる。
- **今回のDLLでは、温度被害で孵化不能になった卵を、その種の無精卵Defへ置換する処理もある。** 孵化先種族のEggLayer設定を参照するため、独自種族で無精卵Defを省略する設計はそのまま流用できると考えない。
- ニワトリ等の卵は食料であり、生食・調理素材の設定も継承している。受精卵は通常食事レシピの初期フィルターでは除外されるが、食用禁止ではない。

バニラ卵箱は容量25・搬出開始20の複数卵向け。`CompEggContainer.Accepts`は受精卵／無精卵カテゴリーを確認する。カエラヴィの出生卵を独立カテゴリー・1個管理にする場合、既存卵箱がそのまま適合するとは扱わない。保管棚等を使い、卵箱なしで孵化させる構成も検討できる。

## 4. 親情報・保存・スタック

`CompHatcher`には、孵化進行度・産卵した親・もう一方の親・所属勢力の保存処理がある。孵化時に親子関係を登録する処理も確認した。

ただし、その情報は**卵アイテムのスタック単位**で保持する。

- スタック結合時の判定には、両親が一致するかの確認がない。
- 結合時は孵化進行度を個数による加重平均へ更新し、吸収した卵の両親を個別に保存しない。
- 分割時は元スタックの進行度・両親・勢力を引き継ぐ。
- 売買により孵化後の所属勢力を書き換える処理もある。

したがってカエラヴィには、**卵を1個ずつ管理し、親・遺伝情報を個別に保存する案**を推奨する。食用・売買の可否は未決定。動物用EggFertBaseを無修正で継承して、これらを暗黙に採用しない。

## 5. カエラヴィへの実装方針案

採用済みの設定は、卵生・歩ける子として孵化・人間との自然生殖・母親側の種族継承。2026-09-20に、孵化直後はRimWorldの人間の3歳相当、**一度の出産（産卵）で1〜3個の卵を産む**指定が加わった。2026-09-21に、**卵の形成6日＋産卵後の孵化12日＝合計18日を基準とする**方針を採用した。1個・2個・3個となる各確率は未定。以下はそれを実装するための提案であり、実装完了の報告ではない。

2026-09-22採用：**孵化後の成長速度・成人となる時期・老化・寿命は、当面人間と同じ基準にする。** 孵化直後の人間の3歳相当という自立度と、飛行開始の約13歳相当は維持する。これらの人間換算と、実際の孵化からの経過年数・内部年齢・画面上の年齢表示の対応は実装時に整理する。

| 部分 | バニラの利用候補 | 接続・変更が必要な点 |
|---|---|---|
| 自然生殖 | 人型の恋愛・夫婦・妊娠判定の既存処理 | `JobDriver_Lovin`は`PregnantHuman`を付ける経路。カエラヴィ母親の場合を産卵へ接続し、通常の出産との二重発生を防ぐ |
| 卵の形成・産卵 | EggLayerの進行度、個数、親の記録、既存産卵Job | 形成期間は6日、一度の産卵数は1〜3個。HumanlikeのThinkTreeには動物の産卵JobGiverがない。形成の開始条件、産卵場所・行動、個数の抽選と受精情報の引渡しを接続する |
| 孵化・温度 | Hatcherの時間経過、TemperatureRuinableの温度被害 | 産卵後12日で孵化し、形成から合計18日を基準とする。安全温度と孵化不能時の扱いは未定 |
| 親子・遺伝 | 親参照とParent関係、Biotechの遺伝処理 | 動物用Hatcherは人型の遺伝GeneSetを引き渡す処理ではない。母親側の種族選択、個別形質の継承と保存を接続する |
| 生まれる子 | Pawn生成、既存の健康・年齢管理 | 専用PawnKindとライフステージ。ゲーム内の人間の3歳相当で孵化し、その後の成長速度・成人時期・老化・寿命は当面人間基準。内部年齢・表示・育児・描画を整合させる |
| 卵の保管 | 通常の運搬・保管・室温管理 | 1個管理、食用・売買の可否、適切な保管分類。独自孵卵器は必須にしなくてよい |

人間の母親から生まれる子については、母親側の人間種族を使う方針と整合させる。人間側の出生まで「歩ける孵化子」に変更しない。

**推奨する最初の構成：自然生殖 → 卵の形成6日 → 1〜3個を産卵 → 適温で12日経過 → RimWorldの人間の3歳相当のカエラヴィの子。** 形成から孵化まで合計18日を基準とする。孵卵器や新しい世話ゲージを先に増やさず、標準の保管・室温管理と人型の育児へ接続する。一度に複数を産んでも、親・遺伝情報を持つ卵を1個ずつ管理する案と矛盾しない。

未決定の設定は、1〜3個の各個数の確率、安全温度、無精卵の有無、食用・売買、個別形質の遺伝、飛行以外の重力操作の習得時期。孵化直後の自立度はゲーム内の人間の3歳を基準とし、その後の成長・老化・寿命は当面人間基準、飛行は人間換算で約13歳から使える設定とする。形成6日・孵化12日はカエラヴィ用に採用した基準であり、バニラの空腹等による進行補正をどこまで引き継ぐかは実装時に確認する。ニワトリの毎日1個・3.5日孵化をカエラヴィへ自動採用しない。
