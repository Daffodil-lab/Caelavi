# 展翼飛行のアルファ仮値

2026-09-24。ここに挙げる数値はゲーム内調整用の仮値で、設定の正式な決定ではない。

| 条件 | 移動速度 | VEF射撃回避 | 通行可能な地形の追加移動コスト | 空腹進行 | 覚醒時の休息消耗 |
|---|---:|---:|---:|---:|---:|
| 両翼 | +0.45セル/秒 | +0.10 | 60%軽減 | 1.25倍 | 1.25倍 |
| 片翼 | +0.25セル/秒 | +0.05 | 30%軽減 | 1.15倍 | 1.15倍 |
| 両翼欠損、翼保護装備、収納中、13歳未満 | なし | なし | なし | 通常 | 通常 |

人間の基本移動速度に対する増加を約1割に抑え、片翼は全効果を弱めた。維持負担は通常の食事・休息の仕組みで観察しやすい25%増から始める。片翼でも継続飛行を可能にするため、効果と負担の両方を減らした。13歳は生物年齢で判定する。孵化時は人間の3歳相当として生成する方針と整合する。

`CA_DeployedFlight` のHediff段階が移動速度・VEFの `VEF_RangedDodgeChance`・空腹/休息消耗を与える。装備が `CA_Wings` BodyPartGroupを覆うと段階を外す。左右の `CA_Wing` の `Hediff_MissingPart` を個別に数える。通常の傷による細かな減衰は未決定のため今回含めない。翼を両方失っても手動の展翼状態は保存し、回復時は効果を再開する。

悪路は Core 1.6 の `Pawn_PathFollower.CostToMoveIntoCell` と `PathGrid.CalculatedCostAt` から、地形が実際に増やしたコストだけを軽減する。VEF Floatingは追加コストを丸ごと消す二値方式であり片翼の段階差に向かないため使わない。通行不能地形の移動は解禁しない。経路選択の評価はバニラのままで、移動中に払うコストだけを減らす。VEF等ですでに浮遊/水上移動になった場合は二重軽減しない。

展翼は手動で、時間制限による解除を設けない。眠り・気絶・装備変更でも手動状態は保持する。休息消耗はバニラの覚醒時の減少に倍率が掛かるため、睡眠中に休息が減るわけではない。これらの細かな停止・再開条件は未決定のため、実機確認後に調整する。

確認が必要: 13歳到達と手動操作、左右の欠損/治療、翼保護装備の着脱、各Hediff段階の値、空腹/休息の時間変化、泥・砂・浅瀬での移動、セーブ/ロード、他のVEF浮遊効果との共存。静的ビルドだけでは動作確認としない。
