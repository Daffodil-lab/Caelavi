# 卵生アルファ実装の仮値と検証点

2026-09-24。これは[採用済みの出生仕様](species-life-appearance-apparel-draft-2026-09-18.md)を試すための実装記録。ゲーム内確認の結果ではない。

## 接続

- Biotechの自然生殖はそのまま受精判定、父親の参照、継承GeneSetの生成を行う。カエラヴィ母親の`RaceProperties.gestationPeriodDays`だけを6に設定した。
- 人型妊娠の満了時に呼ばれる`Hediff_Pregnant.StartLabor`をカエラヴィ母親の場合だけ差し替え、独立した卵を1〜3個置く。人間母親の妊娠・出産には介入しない。この接続点は自然妊娠以外のBiotech妊娠にも作用する。
- 各卵は最大スタック数1。母・父・産卵時の勢力・継承GeneSet・孵化経過tickを個別に保存する。`CompHasPawnSources`で卵が保持する両親のWorldPawn参照を維持する。
- `CompTemperatureRuinable`が孵化不能としなければ、産卵から12日後に`CA_DevelopmentPawn`から子を生物年齢3歳・表示上の暦年齢3歳で生成する。卵内のGeneSetを`forcedEndogenes`へ渡し、父母に`Parent`関係を付ける。発達段階は`Child`。カエラヴィ共通羽は別途、種族固有の非遺伝外見Geneで保証される。
- 卵の仮PNGは`tools/generate_egg_placeholder.py`だけで新規生成した透明画像。正式な卵デザインではない。

## 調整用仮値と理由

| 項目 | 仮値 | 理由・未決定の点 |
|---|---|---|
| 一度の産卵数 | 1、2、3を等確率 | 採用範囲の動作確認を先に行う。正式な確率分布は未決定 |
| 安全温度 | 0〜50℃ | バニラ受精卵の値を検証用に仮置き。カエラヴィの採用温度ではない |
| 温度被害速度 | `0.00003`/℃/tick | バニラ受精卵の検証用仮値。被害100%後は卵が残るが孵化しない |
| 食用・売買・無精卵 | 食用と売買を無効、無精卵は未実装 | 設定が未決定のため、生きた子の意図しない消費・売買を避ける |
| 兄弟の遺伝子 | 最初の卵に妊娠時のGeneSet、2・3個目に両親から再抽選 | 卵ごとに独立した記録を持たせる。再抽選に失敗した場合は妊娠時のGeneSetをコピー |
| 孵化時の暦年齢 | 3歳 | 3歳相当の体格・行動・画面表示を揃えるためのアルファ方式。孵化からの実経過年数の表示方法は未決定 |

## 未確認とゲームでの確認

静的なDef確認やC#ビルドは、ゲーム起動・実際の妊娠・孵化・セーブ読込の証明ではない。専用テストセーブで次を確認する。

1. カエラヴィ母×カエラヴィ父、カエラヴィ母×人間父、人間母×カエラヴィ父の自然妊娠。母側の出生方式・子の種族と、二重出産がないこと。
2. 形成中の保存読込で父親と継承GeneSetが保たれ、およそ6日で1〜3個の卵ができること。卵はスタックせず、複数の母親の卵が混ざらないこと。
3. 卵の保管中と親の離脱後に保存読込し、進行度・父母・GeneSet・勢力が維持されること。母が不在でも親子関係が正しく登録されること。
4. 安全温度の卵がおよそ12日で孵化し、子がカエラヴィ・3歳のChild・親の継承endogene・父母の`Parent`関係を持つこと。関係の重複警告が出ないこと。
5. 温度被害100%の卵が孵化しないこと。卵を運搬・保管棚・キャラバンで保持した場合と、再起動後の孵化経路を確認すること。

現在の妊娠Hediffはバニラの`PregnantHuman`を使うため、説明文中の「18日」とカエラヴィの形成6日が一致しない。アルファUIの制約として記録し、種族専用Hediffへ切り替える段階で修正する。
