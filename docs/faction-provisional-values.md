# 民主共和国の生成用仮値

2026-09-24。ここは勢力・PawnKindのアルファ動作確認に必要な仮値の台帳。部隊編成、装備世代の配分、出現率、交易、初期友好度の正式決定ではない。

| 項目 | 仮実装 | 理由と未決定の点 |
|---|---|---|
| 初期外交 | Coreの非敵対FactionDefを継承し、初期goodwill 0のNeutral | Core 1.6の`Faction.TryMakeInitialRelationsWith`は`naturalEnemy=false`・`permanentEnemy=false`なら0を使う。友好的な中立姿勢を説明文へ記す。正の初期数値や固定同盟は未採用 |
| 世界生成 | `requiredCountAtGameStart=1`、Outlanderの集落生成土台 | まず世界に一つの共和国勢力が作られることを確認する。集落数と出現率は今後調整 |
| 民間人 | CombatPower 45、Coreの`SimpleGun`/`PumpShotgun`、武器予算250〜400、衣服200〜400 | 独自の第1〜第2世代民間銃が未実装のため、動作確認用のバニラ装備。第3世代のOdysseyユニーク銃は生成しない |
| 共和国軍 | CombatPower 80、Coreの`IndustrialGunAdvanced`/`SpacerGun`、武器予算500〜1400、衣服500〜900 | 第2〜第4世代混在の見た目と戦闘生成を仮確認する。個別武器、兵科、比率を決めたものではない |
| 生成集団 | Peaceful=民間人、Combat=軍人、Settlement=民間人と軍人を各重み1 | Def参照と生成の最小証明。重み1は人数や最終比率の決定ではない |
| 交易 | Outlander基底からの商人種類をこの段階では空にする | 共和国商人のPawnKind・品揃えが未定のため。交易は後段の実装対象 |
| 盟主駐留部隊 | PawnKind・pawnGroupMakerを作らない | 設定上は存在してもゲーム中には生成しない。装備のプレイヤー製造経路は後段で作る |

共和国の民間・軍用PawnKindは`CA_Caelavi`種族で、外見Geneは種族共通の処理に任せる。FactionDefの基底に含まれる人間のpawnGroupMakerを置換し、Coreの入植者・衛兵が混入しないようにした。現在の仮武器タグは品目表の個別採用を意味しない。

静的XML検査とゲームロードを分けて記録する。ゲーム内では共和国の生成・中立関係・集落・民間/軍用ポーンの種族、装備、赤ログ、保存再読込を確認する。独立系特派員の加入イベントは別のアルファ実装として追加したが、発火と加入は未確認。開始シナリオ、連邦共和国、盟主駐留部隊はこの段階に含まない。
