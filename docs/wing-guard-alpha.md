# 試作翼ガードの仮値

2026-09-24。`CA_WingGuardAlpha` は、翼を覆う装備で飛行効果が停止する仕様を確認するための独立したアルファ試作品。正式な共和国の衣服・防具品目への採用ではない。

| 項目 | 仮実装 | 理由 |
|---|---|---|
| 名称 | 試作翼ガード／temporary wing guards | 検証用装備であることを明示する |
| 被覆 | `CA_Wings` のみ、`Belt`層 | 左右翼を防護し、胴・腕など既存衣服との競合を避ける。Coreのシールドベルトと同様、着用中の追加グラフィックはまだ無い |
| 材料と工数 | Steel 25、ComponentIndustrial 1、WorkToMake 6000 | Coreの`ArmorMachineableBase`を利用し、加工台の製作レシピを自動生成するための少量の仮材料 |
| 研究 | Core `Machining` | 新規研究Defを設けず製作可能にする試験用ゲート |
| 価格 | 基本市場価値 110シルバー | 材料と工数に見合う調整用の仮値。品質・状態で実際の取引価格は変わる |
| 防御 | Sharp 0.45、Blunt 0.20、Heat 0.10 | 翼の防護と飛行停止を観察できる中程度の仮性能。素材倍率は付けない |
| その他 | 耐久120、質量2、装備時間3、日次摩耗0 | 装備テスト中に破損で状態が変わりにくい設定 |

アイコンは`tools/generate_wing_guard_icon.py`で白紙から生成する透過PNG。正式な着用外見は未制作であり、現在は装備欄と地面上のアイコンで識別する。`CA_Wings` BodyPartGroupを持たない通常のHumanには装着できない想定だが、装備可否、左右翼への防御適用、展翼効果の消失、脱衣後の再開はゲーム内で確認する。
